# School CMS — Електротехничка школа „Михајло Пупин“

Ово је нови сајт и сопствени CMS за Електротехничку школу „Михајло Пупин“, Приштина – Сушица.

Пројекат је намењен часовима предмета „Алати за управљање садржајима на интернету“. Странице сајта су направљене. На часу се садржај мења кроз CMS на `/admin`: вести, галерија, контакт, мени и корисници.

Постојећи сајт [ets.edu.rs](https://ets.edu.rs/) служи као извор информација о школи. Овај пројекат не копира WordPress тему.

## Технологије

- Next.js, React и TypeScript
- Material UI (MUI)
- MongoDB и Prisma
- REST руте у `app/api`
- Пријава: лозинка се чува као хеш, сесија је у httpOnly колачићу

База је MongoDB. Вести, категорије, странице и корисници су повезани у Prisma схеми, у фајлу `prisma/schema.prisma`.

## Како се покреће сајт

Потребни су Node.js 22 и npm.

```bash
npm install
copy .env.example .env
npm run dev
```

Сајт је на [http://localhost:3000](http://localhost:3000).

Почетна страна ради и без базе. За пријаву у CMS база мора бити покренута.

## База

У `.env` упишите `DATABASE_URL` своје MongoDB базе (локалне или Atlas).

```bash
npm run db:setup
```

`db:setup` прави колекције и уписује администратора, вести, страницу О школи, категорије, галерију, мени и подешавања.

Корисне команде:

| Команда | Шта ради |
| --- | --- |
| `npm run db:generate` | Освежава Prisma клијент после измене схеме |
| `npm run db:push` | Шаље схему у MongoDB |
| `npm run db:seed` | Уписује администратора и почетне податке |
| `npx prisma studio` | Преглед колекција у прегледачу |

## Променљиве окружења

Пример је у `.env.example`. Прави `.env` се не шаље на Git.

| Променљива | Значење |
| --- | --- |
| `DATABASE_URL` | Адреса MongoDB базе |
| `AUTH_SECRET` | Тајна за сесију, најмање 32 знака |
| `ADMIN_NAME` | Име првог администратора |
| `ADMIN_EMAIL` | Е-пошта за пријаву у CMS |
| `ADMIN_PASSWORD` | Лозинка првог администратора |
| `NEXT_PUBLIC_SITE_URL` | Адреса сајта |

Лозинка базе стоји само у `.env`. Тај фајл се не шаље на Git.

## Администратор

1. Попуните `ADMIN_EMAIL` и `ADMIN_PASSWORD` у `.env`.
2. Покрените `npm run db:setup`.
3. Отворите [http://localhost:3000/admin](http://localhost:3000/admin).

Ако заборавите лозинку, промените `ADMIN_PASSWORD` и поново покрените `npm run db:seed`. Та команда мења лозинку администратора. Вести и подешавања која већ постоје у бази не преписује.

У фази 1 у панел улази само улога `ADMIN`. Улоге `EDITOR`, `AUTHOR` и `STUDENT` већ постоје у схеми, али још немају приступ.

## Како су сложени подаци

Почетна страна не чита базу директно.

```text
компонента
  → services/
      → Prisma         кад је MongoDB доступна
      → data/          кад база није доступна

app/api/.../route.ts
  → исти сервис
```

Пример: картица вести зове `getLatestArticles()`. Та функција је у `services/articles.ts`. Ако је база доступна, чита објављене вести из ње. Ако није, приказује пример из `data/articles.ts`. Иста функција служи и рути `GET /api/articles`.

Почетни подаци се уписују командом `npm run db:seed`. После тога измена у `/admin` одмах се види на сајту. Ако је база пала, сајт поново показује пример из `data/`.

## Структура пројекта

```text
app/
  (site)/              јавне странице сајта
  admin/login/         пријава
  admin/(panel)/       уређивање садржаја
  api/                 REST руте
components/
  layout/              Header и Footer
  home/                секције почетне стране
  pages/               заглавље и текст унутрашњих страна
  common/              картице и заједнички делови
  admin/               панел и форме
data/                  пример садржаја кад база није покренута
services/              функције које компоненте зову
theme/                 MUI тема и боје школе
prisma/schema.prisma   модел базе
proxy.ts               заштита путање /admin
public/uploads/        стари локални фајлови
```

Јавне адресе:

- `/` почетна
- `/vesti` и `/vesti/slag` вести
- `/o-skoli` текст из CMS странице `o-skoli`
- `/obrazovni-profili` и `/obrazovni-profili/slag`
- `/projekti`
- `/takmicenja`
- `/galerija` слике из медија
- `/kontakt` адреса и телефони из подешавања

Главни мени се уређује на `/admin/menus`. Пример ставки је у `data/navigation.ts` и користи се док база није доступна.

Профили, пројекти и такмичења су у фајловима `data/`. Вести, страница О школи, галерија, контакт, мени, категорије и корисници иду кроз базу.

## API

| Метода | Путања | Ко је користи |
| --- | --- | --- |
| GET | `/api/articles` | објављене вести |
| POST | `/api/articles` | нова вест, само администратор |
| PUT, DELETE | `/api/articles/[id]` | измена и брисање вести |
| GET | `/api/pages` | објављене странице |
| POST | `/api/pages` | нова страница |
| PUT, DELETE | `/api/pages/[id]` | измена и брисање странице |
| GET, POST | `/api/categories` | списак и нова категорија |
| PUT, DELETE | `/api/categories/[id]` | измена и брисање категорије |
| POST, DELETE | `/api/uploads` | слика за вест, само администратор |
| GET, PUT | `/api/settings` | подешавања школе |
| GET, PUT | `/api/menus` | главни мени |
| GET, POST, DELETE | `/api/users` | корисници |
| POST | `/api/auth/login` | пријава |
| POST | `/api/auth/logout` | одјава |
| GET | `/api/auth/me` | тренутни корисник |
| GET | `/api/health` | да ли база ради |

Унос, измена и брисање траже пријављеног администратора.

## Шта је урађено

- респонзивна почетна страна и унутрашње странице менија
- MUI тема
- пријава, одјава и заштићен `/admin`
- форме за вести, категорије, медије, кориснике, мени и подешавања
- кад MongoDB није доступна, сајт и даље приказује пример из `data/`

## Шта остаје за часове

Садржај се мења у `/admin` после `npm run db:setup`. Поновни `npm run db:seed` освежава лозинку администратора и адресе у менију, а постојеће вести не преписује.

Образовни профили, пројекти и такмичења и даље стоје у `data/programs.ts`, `data/projects.ts` и `data/activities.ts`.

Фотографије на почетној страни су привремене илустрације. Школске фотографије улазе кроз Медије.
